## ✨ Features

- Praćenje tramvaja i autobusa uživo na karti Zagreba, s jasno označenim linijama  
- Pronalaženje tramvajske i autobusne stanice na karti grada  
- Provjeravanje voznog red linija prije polaska ili presjedanja  
- Dijeljenje putovanja tramvaja ili autobusa putem linka (klik na vozilo → "Podijeli")  
- Pregled Bajs stanica (najam bicikala) uz kartu prijevoza
