<h1 align=center>ZET Web (ZET Uživo)</h1>
<p align=center>Aplikacija za praćenje ZET vozila uživo.</p>
<p align=center>Backend: <a href="https://github.com/knork-fork/zet-gtfs-backend">zet-gtfs-backend</a> </p>

## ✨ Features

- Praćenje tramvaja i autobusa uživo na karti Zagreba, s jasno označenim linijama  
- Pronalaženje tramvajske i autobusne stanice na karti grada  
- Provjeravanje voznog red linija prije polaska ili presjedanja  
- Dijeljenje putovanja tramvaja ili autobusa putem linka (klik na vozilo → "Podijeli")  
- Pregled Bajs stanica (najam bicikala) uz kartu prijevoza

## 🔨 Built With

- [Vue 3](https://vuejs.org/)
- [Vite](https://vitejs.dev/)
- [Vuetify](https://vuetifyjs.com)

## Install the dependencies

```bash
npm i
```

### Start the app in development mode (hot-code reloading, error reporting, etc.)

```bash
npm run dev
```

### Build the app for production

```bash
npm run build
```
